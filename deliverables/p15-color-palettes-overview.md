# P15 · 配色方案 A/B 对比 — 交付概览

## 本轮做了什么

用户拍板「配色也一起换，先出两版对比看看」，解除了 P14 §12.3 的方向变更待拍板项。按「先规格，后出图」与放量闸门，本轮**只出 2 张配色评审基准图**，未批量出资源、未改动线上任何界面/样式/源码、未发布。

| 文件 | 内容 |
|---|---|
| `律动跑酷-配色A-深空霓虹.svg` | A 版评审稿：菜单屏 + 游戏 HUD + 12 色语义色卡（hex/用途/对比度）+ 设计意图与风险 |

## 两版要点

| | A 深空霓虹 | B 熔岩运动 |
|---|---|---|
| 气质 | 冷 / 电子竞速 / 延续 v1 霓虹 | 暖 / 体感能量 / 换气质 |
| 底色 | `#080B16` | `#120D0B` |
| 主强调 | `#22E1FF` 青 | `#FF7A1A` 能量橙 |
| 与 v1 关系 | 统一（青紫金粉全保留） | 重定（只保留焦点金） |
| 改动面 | 小（主要改 4 个浅色屏） | 大（9 屏全换） |

**两版共同解决**：现状「浅色信息外壳 + 霓虹暗色舞台」双轨割裂；都收敛为 9 屏统一的一套暗色语义色板（12 个 `--c-*` token）。两版都是深底，因为 TV 在暗客厅 / 3m 观看距离下大面积浅底刺眼。两版都刻意避开被否决的 V2 糖果卡通路线。

**保持不变**：P14 版式规范全部数字、TV 金圈焦点 `#FFB020`、Joy 图标、分组列表、强横排、图内不放文字、无意义 tips 禁令、es2015 + CSS 老内核降级红线。

## 对比度（WCAG 2.1 公式实算）

| 色对 | A | B |
|---|---|---|
| 主文字 `ink/bg` | 18.14:1 | 18.05:1 |
| 次文字 `ink2/bg` | 8.11:1 | 8.97:1 |
| 主强调 `brand` | 12.42:1 | 7.40:1 |
| 焦点环 `focus` | 10.73:1 | 10.55:1 |

`accent` / `danger` 在 5.3–5.9:1（AA），**只用于大字号/图标/描边，不承载 B2 24u 以下正文**；正文一律落在 `bg`/`surface` 上（≥8:1）。

## 关键判断与风险

1. **推荐 A**：延续用户已认可的霓虹暗色调性（V2 糖果卡通重设计被否决），是「统一」不是「推翻」，改动面与返工风险最低；游戏屏已是这套色。B 的唯一强理由是「一眼看出换了新 UI」，属产品判断。
2. **换配色 ≠ 改一行 CSS**：现状 110 个硬编码 hex / 248 次出现，落地前必须先做 12 个 `--c-*` 语义 token 化；浅色外壳的 `rgba(0,0,0,.07)` 分隔线与浅阴影必须同步换暗底版。
3. **两版都不承诺「生成即可用」**：图内是规格示意，真正位图需人工精修；B 版 Joy 蓝柄 `#2f80ff` 在暖底对比度下降需加描边或换色；emoji 图标建议随图标家族换成 SVG symbol。
4. 不建议第一版就做「A 体系 + B 主色」混搭，会破坏 12 token 的对比度配平。
