## 一、首进设备昵称引导（需求 1）

- **首次进入本设备自动弹昵称欢迎弹窗**：「👋 欢迎来到 WarmingUp —— 先给自己起个名字吧」，
  主按钮「保存并开始」，欢迎态隐藏取消键（引导设置）。
- 保存后**右上角常驻显示昵称 chip**（菜单顶栏），**重复进入自动沿用**（localStorage 持久化，
  不再弹窗）；点击 chip 或档案头部名字随时可改。
- 昵称全局统一：PK 对战、排行榜、在线列表、档案都认同一个名字（wu.lbName）。
- 弹窗为自绘弹层（原生 prompt 红线不动，APK 横排兜底随屏旋转）。

## 二、设置页重排（需求 2）

旧版：三段标题 + 大卡片平铺。新版：**iOS 式分组列表**——

| 分组 | 内容 |
|---|---|
| 动作识别 | 三行单选（本机摄像头 / 手机当识别器 / 手柄·键盘）：行=图标+主副文案+右侧对勾，选中行浅蓝高亮；手机识别行下展开配对卡（二维码）；行尾两按钮：投屏到电视、设备体检 |
| 主题装扮 | 背景 / 领操员两行（行头图标+说明，行内胶囊 chips 缩进排列，锁定装扮带 🔒⭐ 价签）；恢复默认装扮 + 存储说明 |
| 判定与帮助 | 判定校准行（说明 + 数值 + 滑杆）、跟节拍自动校准、动作清单折叠卡 |
