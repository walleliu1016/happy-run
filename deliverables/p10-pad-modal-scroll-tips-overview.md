# 手柄向导：弹层可滚动 + 清无意义 tips（p10）

## 修了什么

**① 弹层没法滚动（截图里的问题）**
根因：弹层卡片没有高度上限也没有内部滚动，小屏（尤其横排兜底旋转后可视高度=手机短边）内容直接溢出被裁掉，底部按钮都够不着。
修复：所有自绘弹层（手柄向导/昵称/邀请/校准）统一「限高 + 内部滚动」——内容多长都能滚到底，「知道了」按钮始终可达。已在 390×320 小视口实测：内容 442px 高、可视区 296px，可顺畅滚到底。

**② 无意义 tips 全清**（这条记成长期规矩：UI 文案不要任何无意义的 tips）

| 删掉的废话 | 为什么删 |
|---|---|
| 「（网页代替不了）」 | 自我解释说教，用户不关心为什么 |
| 「拿手柄随便按一个键就行」 | 和标题「按手柄任意一键」重复 |
| ③ 步骤下「A跳 B踩 X挥 Y蹲 · 摇杆/十字键移动 · L/R 跑」 | 按键映射，跟「连接」无关，放错了场景 |
| 原始手柄 id 列表（小字断行） | 开发者噪音，绿色状态条已显示设备名 |
| 徽章「点「Joy 手柄怎么连」看步骤」 | 啰嗦指路，按钮就在旁边 |

保留的关键信息（每句都有用）：Joy-Con 配对方法（长按侧面小圆钮）、「浏览器要按键一次才会识别」（不做这步必然以为坏了）、①②③三步、绿色=连好。
设置页手柄源行的「A跳 B踩…」是按键映射速查，场景正确，保留。

## 现在的向导长这样

- 标题：Joy 手柄怎么连
- 一行引导：先在**系统蓝牙设置**配对，再回这里按任意键。
- ① 系统蓝牙配对（含 Joy-Con 配对细节）
- ② 回这里按手柄任意一键（浏览器要按键一次才会识别）
- ③ 变绿 = 连好了
- 检测条：⏳ 等待手柄… 按一下任意键 → ✅ 已连接：设备名
