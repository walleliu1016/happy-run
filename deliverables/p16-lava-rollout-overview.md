# P16 交付概览 · B 熔岩运动配色全量落地 + TV 响应性根治

**2026-11-26 · 触发：用户「选B」**

## 做了什么

1. **B 版配色全量落地（暗色单轨）**：12 个 `--c-*` 语义 token 建齐，164 处硬编码 hex → token/暖色、44 处 rgba → 暗底白描边/暖色，11 个旧变量名保留为兼容别名。9 屏 + 12 弹层 + HUD + 关卡海报 + 分享海报 + 赛道动作色统一；Joy 图标加浅色描边、造型不动。
2. **老内核 CSS 降级**：`inset:0` 20 处展开四值、70 处 clamp 补固定 px 回退、`:has()` 2 处改 `.pip-on` + JS 同步、`aspect-ratio` 用 `@supports not` 兜底、`cqw` 补 px 回退。
3. **TV「不灵敏 / 卡顿」根治**：按键桥每键跨桥 2→1 次、长按 repeat 90ms 双保险节流、焦点几何缓存（一次批量读 rect，按键纯算术）、滚动移到下一帧、焦点环去大模糊与 scale、TV 下关无限扫光动画。
4. **修掉历史 bug**：组件自带 `box-shadow` 后写覆盖 `.tv-focus`，导致横幅类组件上金圈从未显示；`overflow:hidden` 分组卡把外扩焦点环裁成「横贯金线」。已用 `!important` 兜底 + 分组内 inset 双环解决。
5. **APK v1.5**：`versionCode 6` / `versionName 1.5`、URL 缓存戳 `&v=1.5`，CI 自动出版本化 Release。

## 关键决策

- **不推翻 v1 玩法与交互资产**：版式数字（P14）一项未动；只换配色 + 规格体系，避开被否决的 V2 糖果卡通路线。
- **一次做完 9 屏，不留在「只改菜单等确认」**：token 化本身是全局动作，且用户常设规矩是「改彻底、不留半截」。
- **装饰渐变不入语义 token**：关卡海报 / 段位金属色 / SPACE·CANDY 舞台主题色按屏分组管理，只做冷→暖重配，保留关卡识别度。
- **二维码保持纯白**：扫码识别需要，不随暗色单轨改。
- **DOM 项目不切九宫格位图**：底板/按钮/卡片纯 CSS；四具名边界值仅作未来移植引擎的存档规格。
