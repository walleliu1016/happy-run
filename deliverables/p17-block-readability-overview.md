# P17 交付概览 · 迎面块可读性根治

## 做了什么

用户问「为什么所有迎面来的块都看不清」。先做同条件 A/B 复现（P16 前 / P16 后各跑 5 帧真实开局 + 像素亮度扫描），确认**不是 B 版配色回归**，而是两个一直存在的结构性缺陷：

- 地面踏板水平贴地，被 2.9u 俯视透视压成 0.35–4px；
- 白色动作符号叠在亮度 225/255 的巨型日盘上，对比仅 1.31:1。

随后一次性修完并覆盖发布（链接不变），**APK 无需更新**。

## 关键决策

1. **可读性优先于配色统一**：没有回退 B 版暖色，也没有靠「把背景压暗」硬凑对比，而是给每个动作块加不透明深炭底板 `#0B0709`，让对比度与舞台明暗彻底解耦 —— 四个主题与自定义背景图都成立。
2. **把水平踏板竖起来**（`rotation.y=π`），保留底缘 6px 亮带作「贴地踏板」语义，不推翻既有玩法资产。
3. **距离补偿 `k = 1 + clamp((z-18)/90,0,1)×1.15`**，远处放大到 2.15 倍、近判定线平滑回落，避免近处块过大遮挡 HUD。
4. **日盘半径 72→52u、y 17→26u、光晕 0.35→0.22**：不动色相，只改构图，给消失点留出暗带。
5. **动作色只提亮两档**（`squat #FF5C6B` / `right #FF9A3D`），12 个 `--c-*` 语义 token 与 P14 版式数字一项未动。

## 验证数字

- 对比度：白符号 vs 底板 **20.03:1**、底板 vs 亮日盘 **11.65:1**（修复前 1.31:1）
