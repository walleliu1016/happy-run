# 交付总览 · PK 关卡下拉改自绘选择器（2026-11-24 第四批）

## 问题

用户反馈：**在 APK 里进 PK 模式，选关卡的下拉框「变成竖的」了。**

## 根因

APK 的 WebView 里 `screen.orientation.lock` 通常不生效，网页走的是 CSS 兜底横排
（整个界面旋转 90° 呈横排）。但原生 `<select>` 的下拉弹窗由**系统按窗口方向（竖屏）绘制**，
不跟 CSS 旋转走——于是弹窗在横排界面里「竖着」弹出来。

## 修法（彻底：弃用原生控件）

- 关卡下拉改为**自绘选择器**：弹层是页面 DOM，跟着界面一起转，任何环境下方向都正确
- 弹层贴「最近裁剪祖先」的可见边界：放不下自动**向上弹 + 收窄高度**，选中项自动滚入
  可视区，其余选项内部滚动可达
- 选项紧凑化（5 关常规场景全部直接可见）；点外部 / 按 Esc 收起；选中项紫色高亮

## 验证（playwright 双场景 9/9 + 目检）

- 竖屏窗口兜底横排（APK 复现环境）：菜单随界面同向旋转、完整不被裁切、选中项
  LV1 紫色高亮可见、选 LV2 后建房→大厅显示「玻璃桥」（选择正确传递）✓
- 真横屏回归：下拉选择正常 ✓
- 线上抽验：自绘选择器代码已生效 ✓

## 备注

文本框的输入法（IME）弹窗同理由系统绘制、网页侧无法旋转；若 APK 里输入昵称时
键盘方向不对，需在 APK 壳里把 Activity 锁定为横屏（网页代码管不到系统键盘）。
