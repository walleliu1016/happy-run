# WarmingUp 律动跑酷 · 第 11-19 轮改造总览

## 第 19 轮（最新）：菜单 UI 交互重构——三步引导流程
用户反馈「内容平铺一个页面、没有交互」。把 5 张设置卡一面墙重构为引导式开玩流程：
- **三步引导**：①玩法（玩给谁+难度）→ ②识别（识别器+配对卡滑出）→ ③装扮（音乐+主题+折叠工具卡），
  顶部步骤药丸可直达，分步动画切换
- **常驻玻璃底栏**：实时配置摘要 chips + 上一步/下一步 + 「开始热身」任何一步可开玩
- **微交互**：卡片 ✓ 选中徽章弹入、按压缩放、折叠卡（判定校准/动作清单）、移动端顶栏适配
- 钩子零破坏：全部 ID/data-* 保留；shot15 向导 8 断言 + shot12/14/smoke5 回归全绿

## 第 18 轮：手柄·键盘输入源（Joy-Con 即连即用）
用户问「我有 Joy-Con 可以直接用？」——接通手柄/键盘输入通路，免摄像头免手机：
- **新模块 gamepad.ts**：Gamepad API 轮询 + 键盘兜底，边沿触发 + 140ms 去重
- **映射**：A跳 B踩 X挥 Y蹲 · L1/十字左=左 R1/十字右=右 · L2/R2=跑；摇杆上下=跳/踩、
  左右=移动；键盘 ↑W ↓S ←A →D J挥 K蹲 L跑（空格/Enter 跳沿用既有监听）
- **菜单**：「识别器用哪个」新增第三张卡「手柄·键盘」+ 实时连接状态（✅ 已连接：xxx）
- **多键位冗余**：不同系统对 Joy-Con 单只横握上报不一，每个动作绑多个键位 + 迟滞兜底
- 假手柄端到端实证：七动作轮转 12s → score 0→2550、combo 20，0 真实错误

边界：Joy-Con 陀螺仪需 WebHID（Chrome/Edge 桌面）暂未接、点单可做；Safari/Firefox 按键可用。

## 第 17 轮：识别率提升快赢 + 体感设备路线
用户问「体感设备支持什么的比摄像头更准吧，或者如何提高摄像头识别率」。本轮落地软件侧快赢：
1. **可见度过滤**——33 关键点均值 visibility<0.5 不触发动作（防遮挡误判）
2. **实时提示系统**——底部胶囊提示条（5 秒节流、自动隐藏）：多人入镜警告（检测数 1→2）/
   构图提示（人太大太小、偏站）/ 光线提示（帧均亮度 <42 提示开灯）
3. 提示接入两条识别链路（本机直玩 + 手机传感器模式）

体感硬件路线结论：手机 IMU 手柄（零成本、不受光线影响）> 跳舞毯/踏板（Gamepad API、
按键判定 100%）> 蓝牙手柄；手表手环/Kinect 浏览器拿不到 API，暂不可行。
识别率后续可做：lite→heavy 模型开关、分辨率提档、动作基线校准、IMU+视觉双路融合。

## 第 16.5 轮：投屏向导改版（游戏 vs 视频投屏讲透）
用户核心疑问「跟腾讯视频投屏一样吗？还要电视本地运行？」。讲透原理：视频=推播放地址、
电视自己拉流；游戏每帧实时算没法推地址。两条真路：①手机跑+电视**无线镜像**（电视零操作，
推荐主卡）②电视跑+手机当摄像头（一键投屏，需 Chromecast）。向导页按 UA（iPhone/安卓）
给具体镜像步骤，镜像游玩优先后置摄像头。

## 第 16 轮：投屏功能
一键投屏（Presentation API，投 `?role=cast` 接收端，同配对码手机自动进传感器模式）、
镜像游玩（全屏+横屏锁+WakeLock+本机摄像头直驱）、电视浏览器直开（扫码配对）三路径。

## 第 14 轮：六项生动特效全做
上轮脑暴的六个点子全部落地（用户原话「都做」）：

## 关键改动（改前 → 改后）

| 维度 | 改前 | 改后 |
|---|---|---|
| 节奏块形态 | 立体/飘浮的姿势剪影贴片，迎面飞来 | **平铺路面的深色圆角踏板**（动作色发光描边 + 白边 + 姿势剪影）|
| 摆放逻辑 | 漏斗向中心汇聚、贴片高低错落 | **纯透视车道直线**，踏板沿车道按节拍铺向地平线 |
| 可见距离 | `z < 120` 强制隐藏，到近处凭空冒出 | `z < 620` + 雾距 (110,560)，**提前多排全程可见** |
| 碎裂原点 | 漏斗收敛系数 `baseX*0.22`、y=1.2 | block 走车道本位 `baseX`、y≈0.55（贴路面）|
| 布景主题 | stay-beat 用 candy（粉紫）| stay-beat 改 **neon**（红霓虹峡谷）|
| 青色巨日 | 日盘背面剔除，**根本没画出来** | 修 `DoubleSide`，青色巨日显现（地平线正中）|

## 关键修复：青色巨日不可见的根因
太阳是 `CircleGeometry`（正面朝 +Z），而相机朝 +Z 看的是它的 **-Z 背面**；
`MeshBasicMaterial` 默认 `FrontSide` 背面剔除 → 日盘整面被剔除、一直没渲染。
加 `side: THREE.DoubleSide` 后巨日显现。这与当年姿势贴片需 `rotation.y = Math.PI` 是**同一个相机朝向坑**。
