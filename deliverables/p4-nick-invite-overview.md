# P4 · 昵称 + 在线玩家 + 点对点 PK 邀请 — 交付说明

**上线时间**：2026-11-25 · 提交 3943b87（5 files +534/-18）· 线上已覆盖发布（链接不变）
**需求原文**：增加一个个人信息的显示，设置昵称，显示在右上角，这样 pk 的时候就不要写了，然后增加一个在线用户的模块，这样可以选择用户进行 pk，用户可以选择同意或者拒绝。

## 一、昵称统一（PK 免填）

| 项 | 说明 |
|---|---|
| 显示位置 | 菜单页 + PK 页右上角昵称 chip（`👤 昵称`），多处实时同步 |
| 设置方式 | 点 chip 弹出自绘「设置昵称」弹层（不走原生 prompt，APK 兜底横排随屏旋转） |
| 生效范围 | **一处设置全局通用**：PK 对战、全服排行榜、在线玩家列表同名 |
| 兼容迁移 | 旧「PK 昵称」自动迁移为全局昵称；PK 页不再要求填昵称 |

## 二、在线玩家模块（PK 页）

- 位置：PK 页「公开房间」上方，实时显示当前在线玩家（排除自己）。
- 每行：头像 emoji + 昵称 + 状态操作：
  - 空闲 → **[邀请 PK]** 按钮
  - 对局中 → 🔥 对局中 徽标（不可邀）
  - 已邀 TA → **[等待回应… 撤销]**（可随时撤回）
- 心跳保活 45 秒；顶部「🟢 在线 N 人」实时刷新。

## 三、点对点 PK 邀请（同意 / 拒绝）

1. 点 [邀请 PK] → 对方弹出「⚔️ XX 邀请你 PK」弹窗（含关卡 + 难度），60 秒有效。
2. **接受** → 服务端自动开私密房，双方直接进 VS 倒计时 → 分屏开跑（复用房间对战全链路）。
3. **拒绝** → 发起方收到「✖ XX 拒绝了你的邀请」提示；邀请过期/撤销同样有反馈。
4. 发邀请后自动切换 1 秒快速心跳（平时 5 秒）：发起方尽早拿到房间，双方起跑不偏。

## 五、边界说明

- 在线状态为**同站点在线**（内存态，服务重启即清空）；未做账号体系/跨端在线。
- 邀请 60 秒未回应自动过期；同一时间每人仅能发起/持有一个待回应邀请（发新撤旧）。
- 昵称限 12 字、入库前消毒（`<>"'`& 等字符剔除），列表渲染全部 escapeHtml。
