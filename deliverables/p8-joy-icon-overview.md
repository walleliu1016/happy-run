# P8 改版总览：手柄图标改 Joy 风格（蓝牙体感设备）

**上线时间**：2026-11-25 · **链接不变**

## 背景（用户反馈）

> 不应该用手柄的样式，应该用 joy 的样式，或者能代表这类蓝牙体感设备

原 🎮 是「游戏手柄」emoji，代表不了 Joy-Con 这类**蓝牙体感设备**。

## 改造：Joy 分体双柄图标

自绘 SVG 图标（`#icon-joy`）：**一对分体圆柄**——蓝柄（白色摇杆 + 十字键点）+
红柄（ABXY 键点 + 摇杆），一眼认出 Joy-Con / 蓝牙体感手柄。

### 替换点位（10 处）

| 点位 | 之前 | 现在 |
|---|---|---|
| 菜单顶栏状态 chip | 🎮 手柄未连 | Joy SVG · Joy 手柄未连 / 短名 |
| 设置页识别源行 | 🎮 手柄·键盘 | Joy SVG · Joy 手柄 · 键盘（副文案：Joy-Con 等蓝牙体感手柄直连） |
| 连接向导弹层标题 | 🎮 手柄怎么连？ | Joy SVG · Joy 手柄怎么连？ |
| 向导步骤 ① | 把手柄或 Joy-Con 配对 | 把 Joy-Con / 蓝牙体感手柄 配对到本设备 |
| 游戏 HUD 徽章 | 🎮 短名 | Joy SVG · 短名 |
| 弹层设备列表 | 🎮 设备名 | Joy 小图标 · 设备名 |
| 菜单摘要源 chip | 🎮 手柄·键盘 | 🕹 Joy 手柄·键盘 |
| 连接/断开 toast | 🎮 手柄已连接/断开 | 🟢 Joy 手柄已连接 / ⚫ Joy 手柄已断开 |
| 档案统计/房间卡/就绪提示的装饰 🎮 | 🎮 | 🏃（跑酷语义） |
| TV 遥控提示条 | 🎮 遥控器 | 📺 遥控器 |

全页扫过：**手柄 emoji 零残留**。
